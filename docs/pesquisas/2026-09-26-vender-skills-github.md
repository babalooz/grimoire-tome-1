## Veredito
Vender skills/loops isolados = negócio ruim. Oferta grátis enorme (anthropics/skills ~135k estrelas, SkillsMP >900k skills),
teto dos melhores ~US$2–2,5k/mês, comoditização rápida. Nichos BR já têm MCPs grátis (NF-e, PIX, Hotmart, Kiwify, Evolution API).
Anthropic permite plugins com cobrança à parte — o bloqueio é o mercado, não a política. Esperado: US$0–300/mês.

## 3 jogadas
1. **Repo público "agente-whatsapp-pme"** (Cloud API oficial + n8n + Claude) com plugin Claude Code (`/novo-cliente`, `/deploy-vps`,
   `/relatorio-semanal`), vídeo de 90s e CTA para WhatsApp. Preço: R$1.500–2.500 setup + R$600–900/mês. 90 dias: 2–4 clientes.
2. **Kit open-core PT-BR na Kiwify** (R$197 ou R$47/mês) empacotando a jogada 1. 90 dias: R$2–6k bruto.
3. **Actor Apify de CNPJ em lote** (US$2–5/1.000 resultados) — renda baixa, mas vira ferramenta de prospecção da agência.

Não fazer: GPT Store, packs de prompts, GitHub Marketplace, boilerplate Next.js.
